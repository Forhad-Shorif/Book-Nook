# 📚 BookNook - Modern Library & Community Platform

**BookNook** is a full-stack web application designed for book lovers to explore, share, and manage books seamlessly. Users can browse collections, view detailed book summaries, publish new titles, and borrow or return books in real time.

---

## 🚀 Key Features

- **Explore & Search:** Browse through an extensive collection of books with real-time fetching.
- **Dynamic Book Management:** Add, update, and delete books with a clean, interactive UI.
- **Borrowing System:** Seamlessly borrow and return books with automated inventory tracking.
- **Modern UI/UX:** Built with Tailwind CSS, DaisyUI, and custom glassmorphism styling.
- **Secure Authentication:** Integrated user management and protected routes.

---

## 🛠️ Tech Stack

- **Frontend:** Next.js (App Router), React, TypeScript, Tailwind CSS
- **Icons & UI Components:** Hugeicons, Radix UI / Shadcn UI components
- **Notifications:** React-Toastify
- **Backend & Database:** Node.js, Express.js, MongoDB Atlas
